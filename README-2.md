# Sanwariya Seth Digital Solution — Website

A static, premium-styled marketing website for Sanwariya Seth Digital Solution, built with plain HTML5, CSS3 and vanilla JavaScript only. No build step, no backend, no paid services — it can be hosted for free on GitHub Pages.

## Files

```
index.html   — page structure and content
style.css    — all styling (dark navy + gold theme, animations, responsive layout)
script.js    — mobile menu, scroll reveal, animated demo counters, Telegram copy button
README.md    — this file
```

## Deploy for free with GitHub Pages

1. **Create a GitHub repository.**
   - Go to [github.com](https://github.com) and sign in (create a free account if needed).
   - Click **New repository**. Name it anything, e.g. `sanwariya-seth-website`.
   - Set it to **Public** (GitHub Pages on the free plan requires a public repo, unless you have GitHub Pro/Team/Enterprise).
   - Click **Create repository**.

2. **Upload the files.**
   - On your new repository page, click **Add file → Upload files**.
   - Drag in `index.html`, `style.css`, `script.js`, and `README.md`.
   - Scroll down and click **Commit changes**.

3. **Enable GitHub Pages.**
   - In your repository, go to **Settings → Pages** (in the left sidebar under "Code and automation").
   - Under **Build and deployment → Source**, choose **Deploy from a branch**.
   - Under **Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.

4. **Visit your live site.**
   - Wait 1–2 minutes. GitHub will show a message like: "Your site is live at `https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/`".
   - Open that link — the website is now live and free, with no server or database required.

## Updating the site later

Edit `index.html`, `style.css`, or `script.js` directly in GitHub (click the pencil icon on any file) and commit the change, or upload replacement files the same way as step 2. GitHub Pages will redeploy automatically within a minute or two.
